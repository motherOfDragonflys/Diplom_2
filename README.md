# API-тесты с WireMock  

API-тесты учебного сервиса: проверяются ручки создания пользователя, входа и создания заказа. Часть сценариев выполняется через WireMock — заглушку, имитирующую реальный API.  

## Технологии  

- Java 11, JUnit 4
- RestAssured — HTTP-запросы и проверки ответов
- WireMock — заглушка API для сценариев без реального сервера
- Allure — отчёт о прогоне

## Структура классов  

**src/main/java — общие классы тестового фреймворка**  

- **config**
  - `Config` — базовый URL и адреса стенда (реальный API или заглушка).
- **data**
  - `Endpoints` — константы эндпоинтов API.
  - `UserGenerator` — генерация тестовых данных пользователя (уникальный email, имя, пароль).
- **model**
  - `User` — POJO пользователя: имя, email, пароль.
  - `Order` — POJO заказа: состав и ингредиенты.
- **steps**
  - `CommonSteps` — общие операции: базовая настройка запросов, проверки кодов ответа.
  - `UserSteps` — шаги работы с пользователем: создание, логин, получение токена.
  - `OrderSteps` — шаги работы с заказами: создание заказа, проверка ответа.

**src/test/java — автотесты**  

- **base**
  - `BaseApiTest` — общая настройка RestAssured, базовые фикстуры `Before`/`After`.
  - `BaseUserTest` — подготовка тестового пользователя: создание через API перед тестом, удаление после.
  - `BaseWireMockTest` — запуск и остановка `WireMockServer` перед и после каждого теста, подключение заглушек.
- **config**
  - `WireMockStubs` — описание заглушек: маппинги эндпоинтов на фиксированные ответы (успешные и ошибочные кейсы).
- **tests**
  - `UserCreateTest` — создание пользователя: успешный ответ, дубликат, без обязательных полей.
  - `UserLoginTest` — вход с корректными и некорректными данными.
  - `OrderCreateTest` — создание заказа: с авторизацией, без авторизации, без ингредиентов и с невалидными хэшами ингредиентов.
